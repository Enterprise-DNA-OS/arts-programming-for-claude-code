# Revise production

Read the production first with npm run arts -- production CODE --json. Run npm run arts -- revise-production --production=CODE --owner="Actual owner" --context=dramatic --status=confirmed --actor="Actual operator", supplying only the changes requested. Context accepts unknown, dramatic or other. Status accepts planned, confirmed or closed. A context change causes mismatched rights evidence to appear in rights-due. Confirmed means the recorded production status, not a legal or safety clearance. Rerun compliance after the change. Never send or publish.
