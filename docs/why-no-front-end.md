# Why the programme office works without a front end

A season is productions, works, credits, calls, spaces, rights evidence and actions. Commands answer questions and create drafts from those records. npm run view produces read-only HTML snapshots. npm run docs produces a production brief, programme sheet and safety handover for each production, using brand.json.

A screen provides drag-and-drop calendar changes, live shared updates, phone access and offline capture. This base provides none of those. It also does not sell tickets, sign licences or send call sheets. People operate the database through an agent and review each draft.

Enterprise DNA can add a shared calendar, controlled access, a phone view, ticketing or accounting connections and other agreed work to a customised version. The open source database remains yours.
