# Add a read-only view

Read views.json and the relevant SQL view definitions. Describe the question and use one read-only query over existing records. Add the report to views.json, escaping all record text through the shared renderer. Run npm run view, inspect the resulting file and return its path. Never include private fields or evidence in an externally shared report without the operator reviewing them. No buttons, writes, server or front end.
