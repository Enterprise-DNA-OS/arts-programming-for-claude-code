# add-programme

Run `npm run arts -- add-programme --code=CODE --production=CODE --work=CODE --position=1 --credit="Approved wording" --actor="Actual operator"`. Replace examples with the operator's supplied values. Add --json when the full record is needed.

Read the relevant production and current records first. Validate the requested change, use a named actor, and report the returned record. Never invent permissions or evidence.

All call timestamps are UTC. Rights checks use the production timezone. This command does not send, publish, book a room externally or certify compliance.
