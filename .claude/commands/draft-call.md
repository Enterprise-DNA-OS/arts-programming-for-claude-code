# draft-call

Run `npm run arts -- draft-call --production=TIDE`. Replace examples with the operator's supplied values. Add --json when the full record is needed.

Present the returned records with their codes and dates. Explain missing records explicitly. Never infer an approval from an empty report.

Read the complete production and its notes before drafting. Output is a local draft, never sent or published.
