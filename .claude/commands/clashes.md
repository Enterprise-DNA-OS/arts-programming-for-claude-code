# clashes

Run `npm run arts -- clashes`. Replace examples with the operator's supplied values. Add --json when the full record is needed.

Present the returned records with their codes and dates. Explain missing records explicitly. Never infer an approval from an empty report.

All call timestamps are UTC. Rights checks use the production timezone. This command does not send, publish, book a room externally or certify compliance.
